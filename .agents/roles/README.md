# Reusable roles

These are inactive role briefs, not processes. The primary agent activates at most three specialists with only the relevant Graphify context.

| Role | Use when |
| --- | --- |
| product-manager | outcomes, scope, acceptance criteria |
| technical-program-manager | multi-stage delivery and dependencies |
| software-architect | boundaries, data flow, ADRs |
| frontend-engineer | Angular components, state, accessibility |
| ui-design-engineer | visual refinement and screenshot review |
| backend-engineer | API, auth, services, background work |
| data-engineer | schemas, indexes, retention, backfills |
| integration-engineer | external providers and resilience |
| test-engineer | unit/integration/contract strategy |
| e2e-engineer | Playwright, axe, responsive journeys |
| code-reviewer | correctness, scope, security, maintainability |
| security-engineer | threat model and hardening |
| performance-engineer | profiling, budgets, regressions |
| devops-engineer | CI/CD, build, deployment, rollback |
| sre-engineer | health, SLOs, incidents, capacity |
| observability-engineer | logs, metrics, traces, redaction |
| release-manager | readiness, versioning, smoke evidence |
| documentation-engineer | docs, ADRs, runbooks, accuracy |
